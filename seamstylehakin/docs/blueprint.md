# **App Name**: Hakim Portfolio

## Core Features:

- Instagram Feed Display: Display a dynamic feed of Hakim's latest Instagram posts, updated in real time. Uses the Instagram API.
- Project Gallery: Showcase high-resolution photos of completed projects in a dedicated gallery, each with detailed descriptions of the work done and materials used.
- Contact Form: An integrated contact form allows potential clients to easily reach out for inquiries and custom orders.
- Image Optimization Tool: Use AI tool to suggest compressed file sizes so the images display quickly and save storage space.

## Style Guidelines:

- Primary color: Soft gold (#C4B385) for elegance and sophistication.
- Background color: Cream (#F5F5DC) to provide a clean and soft backdrop.
- Accent color: Muted sage green (#B2BEB5) to add a touch of nature and tranquility, balancing the gold and cream.
- Body font: 'Literata', a serif with a literary and elegant feel. 
Headline font: 'Belleza', a sans-serif with personality aligned to fashion, art, and design. 
This pairing supports readability of large blocks of descriptive text in combination with catchy headlines.
- Use minimalist, line-based icons in soft gold to represent different services or project types, keeping the look refined and uncluttered.
- Employ a clean, grid-based layout with plenty of whitespace to ensure the portfolio is easy to navigate and visually appealing.
- Incorporate subtle, elegant animations for transitions and interactions, such as fade-ins and smooth scrolling, to enhance the user experience.
